# 质量与测试策略

Required checks:
- TypeScript typecheck / renderer build.
- E2E: optimistic user row remains local-first.
- E2E: exactly one assistant-turn for one prompt.
- E2E/regression: multiple tiny deltas render as one text part.
- E2E: final repeated content does not create a duplicate answer.
- E2E: no standalone agent-thinking row on the normal path.
- E2E: composer remains visible during active/long transcript.
- E2E: account Bot hydration does not wait for self-hosted sync.

CI evidence is required before completion. Flaky visual timing assertions use bounded, behavior-based thresholds rather than arbitrary sleeps.
