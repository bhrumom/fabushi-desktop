# 完成定义与验收

Project completion requires all of:
- R1-R6 traced to code and automated evidence;
- typecheck/build pass;
- focused E2E pass;
- PR merged through protected main;
- canonical `main` reread confirms the fix;
- task/WBS/acceptance/status/change records updated with actual commit/PR/CI evidence.

A code commit without CI and canonical-main verification is implementation-in-progress, not complete.
