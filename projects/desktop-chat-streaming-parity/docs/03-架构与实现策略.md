# 架构与实现策略

Keep Rust/Host authoritative. Renderer owns a projection only.

Target turn flow:
1. local send paints optimistic user row and provisional assistant turn;
2. Host acceptance rekeys that provisional turn to the authoritative operation id;
3. thought/tool/body events update the same turn;
4. body deltas append to the same streaming text part;
5. terminal/final payload reconciles rather than appending a second answer;
6. terminal status seals parts after pending stream data is represented.

Reference lesson from Grok App: current-turn assistant binding and stream coalescing are more important than a visual “wrapper”. We apply the pattern without replacing Mahayana.
