### CH-SEND-SETTLEMENT-44: transcript/internal ACK does not wait for channel delivery
`source/host/app/src/main.rs` exact blob `8e19361b3b278d085927a84ea4c8ce8c3fe3de80` was re-read in full (13,719 lines); L780-841 implements `ProductionRunnerSink::send_message`:

The available `tool_call_id` argument is not included in the sent lane payload (only agentId, addressToken, message).
2. **Independently**, L817-838 appends a generated `SendMessage` transcript entry, publishes `transcript/appended`, calls `fulfill_ack_obligation()`, tracks `ActivityUpdate::SendMessage`, then returns the persisted entry ID. L9010-9030 handles subsequent port failure through an error tray/background wake. Neither lane response is a provider receipt or a durable operation result.
