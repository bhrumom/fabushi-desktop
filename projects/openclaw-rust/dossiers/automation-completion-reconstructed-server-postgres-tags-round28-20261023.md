### Mandatory formal API matrix still open

For the *real* Sand owner obtain fixed service repo/commit/tree or officially versioned API definition, request and response examples, principal/tenant lookup, persistence and transaction boundaries, and per-case receipts:
1. **200** body schema, duplicate `runUuid`, same-vs-conflicting result and after-ACK response. Distinguish accepted outcome vs already-settled no-op.
2. **204** legal/illegal status on completion; empty body and client decoding; after server commit but before client receives response.
3. **401** missing/expired/revoked bearer, account A→B, and whether mutation may already have occurred across network ambiguity. Refuse cross-principal completion and ACK; do not misclassify stale auth as success.
4. **404** missing run vs wrong owner vs deleted/expired fire, ACK eligibility and whether a 404 can conceal wrong-principal/credential mistakes.
5. **409** conflicting status/revision/lease vs idempotent already-applied completion; determine whether it is safe to report/ACK.
6. **cancel/stop/restart**: after late completion and credential rotation; pending vs completed vs ACKed vs expired recovery, first-writer-wins rules, retention and reconcile endpoint. **A timeout, network exception, 204 JSON Decode error, 404 or 409 does not prove no side effect or correct authorization.**
